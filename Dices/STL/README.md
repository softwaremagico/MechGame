# Cómo imprimir el dado en varios colores

Para imprimir el dado en varios colores, sigue estos pasos:

1. Exporta desde openscad el cuerpo del dado a un archivo `.stl`.
2. Exporta desde openscad las caras con los valores del dado a un segundo archivo `.stl`.
3. Abre **Bambu Studio** y arrastra ambos archivos `.stl` al mismo tiempo sobre la ventana del programa.
4. Cuando aparezca el mensaje **"¿Desea cargar estos archivos como un único objeto con múltiples partes?"**, selecciona **Sí**.
5. Asegurate de que el orden de los objetos es correcto. El dado tiene que ir antes de los valores para que se visualicen correctamente. 
6. En el panel **Objects (Objetos)**, situado a la izquierda, despliega el modelo y asigna a cada parte el color de filamento que prefieras.

Nota: en el fichero `dados mech game.3mf` tienes un ejemplo ya listo para imprimir.
